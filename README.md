# Simulated-rumor-experiment
An LLM-driven multi-agent simulation framework for studying opinion polarization and rumor propagation on complex networks.
# LLM-Driven Agent-Based Social Simulation

This repository provides a simple implementation of an LLM-driven agent-based simulation framework for studying rumor diffusion, debunking interventions, and opinion dynamics in social networks.

The workflow contains four main steps:

1. Generate heterogeneous agents.
2. Build a social network.
3. Run the LLM-driven simulation.
4. Run Monte Carlo repeated experiments.

---

## File Overview

| File | Description |
|---|---|
| `agent_generator_x.py` | Generates agents with demographic attributes, Big Five personality traits, and interests. |
| `agent_network.py` | Builds social networks, including BA, ER, WS, and Hypergraph-based structures. |
| `prompt_universal.py` | Constructs prompts for LLM agents using personality, memory, and neighbor posts. |
| `LLM_call.py` | Provides a unified interface for calling different LLM APIs. |
| `main_run.py` | Runs one complete simulation experiment. |
| `run_monte_carlo.py` | Runs repeated simulations and calculates mean values and 95% confidence intervals. |

## Requirements

Python 3.9 or later is recommended.

Install the required packages:

```bash
pip install networkx numpy scipy requests openai zhipuai
```

---

## API Key Setup

Before running the simulation, configure your API key.

For example, in Linux or macOS:

```bash
export QWEN_API_KEY="your_api_key_here"
```

In Windows PowerShell:

```powershell
$env:QWEN_API_KEY="your_api_key_here"
```

It is recommended to use environment variables instead of writing real API keys directly in the source code.

Example in Python:

```python
import os

"api_key": os.getenv("QWEN_API_KEY")
```

## Step 1: Generate Agents

Run:

```bash
python agent_generator_x.py --seed 46 --out .
```

This generates agent files such as:

```text
agents_N50_seed46.json
agents_N100_seed46.json
agents_N500_seed46.json
```

The default population sizes are defined in `agent_generator_x.py`:

```python
network_scales = [50, 100, 500]
```

You can modify this list to generate other population sizes.

---

## Step 2: Generate a Network

Open `agent_network.py` and modify the execution settings:

```python
INPUT_FILE = "agents_N100_seed46.json"
OUTPUT_FILE = "net_ba_100_seed46.json"

NETWORK_TYPE = "ba"   # Options: "ba", "er", "ws", "hyper"
AVG_DEGREE = 4.0
SEED = 46
```

Then run:

```bash
python agent_network.py
```

Available network types:

| Option | Network Type |
|---|---|
| `"ba"` | Barabási-Albert scale-free network |
| `"er"` | Erdős-Rényi random network |
| `"ws"` | Watts-Strogatz small-world network |
| `"hyper"` | Hypergraph-based projected network |

The generated network file, such as `net_ba_100_seed46.json`, will be used as the input for the simulation.

---

## Step 3: Modify the Prompt

The prompt template is defined in `prompt_universal.py`.

The prompt includes:

- agent demographic profile;
- Big Five personality description;
- recent post history;
- visible posts from neighboring agents;
- JSON output format.

The current JSON output format is:

```json
{
  "thought_process": "...",
  "is_believed": true,
  "will_spread": true,
  "new_post": "..."
}
```

To change the agent behavior logic, edit the personality descriptions in:

```python
translate_big_five(big_five)
```

To change the number of visible neighbor posts, edit:

```python
neighbor_posts_list = neighbor_posts_list[:8]
```

To change the memory length, edit:

```python
own_history_posts[-3:]
```

No separate system prompt is used. All role instructions, agent information, social context, task instructions, and JSON constraints are included in the user prompt.

## Step 4: Run One Simulation

Open `main_run.py` and modify the configuration:

```python
config = {
    "agent_file": "net_ba_100_seed46.json",
    "model_provider": "qwen",
    "api_key": os.getenv("QWEN_API_KEY"),
    "model_name": "qwen-turbo",
    "temperature": 0.7,
    "rounds": 15,
    "seed_strategy": "structural",
    "initial_spreader_ratio": 0.05,
    "initial_rumor": "Urgent Notice: The east city water source is polluted, do not drink tap water!",
    "enable_debunking": False,
}
```

Then run:

```bash
python main_run.py
```

Key parameters:

| Parameter | Meaning |
|---|---|
| `agent_file` | Networked agent file generated by `agent_network.py`. |
| `model_provider` | LLM provider, such as `"qwen"`, `"deepseek"`, `"zhipu"`, or `"openai"`. |
| `model_name` | Model name used in the API call. |
| `temperature` | Sampling temperature. |
| `rounds` | Number of simulation rounds. |
| `seed_strategy` | Initial rumor seed strategy: `"structural"`, `"psychological"`, or `"random"`. |
| `initial_spreader_ratio` | Proportion of initial rumor spreaders. |
| `initial_rumor` | Initial rumor injected into the network. |
| `enable_debunking` | Whether to inject debunking information during the simulation. |

---

## Debunking Settings

Debunking is controlled by:

```python
"enable_debunking": True
```

In `main_run.py`, the debunking message is inserted in the block beginning with:

```python
if self.config.get("enable_debunking", False):
```

For a baseline rumor diffusion experiment, use:

```python
"enable_debunking": False
```

For a debunking experiment, set:

```python
"enable_debunking": True
```

You can modify the intervention rounds and the official correction text inside this block.

---

## Step 5: Run Monte Carlo Experiments

Open `run_monte_carlo.py` and modify the experiment configuration.

Set the number of repeated runs:

```python
num_runs = 10
```

Then run:

```bash
python run_monte_carlo.py
```

The script calculates:

- mean value;
- standard deviation;
- 95% confidence interval;
- raw data for plotting.

The output file will be saved as a JSON file, such as:

```text
monte_carlo_BASELINE_stats_YYYYMMDD-HHMMSS.json
```

or:

```text
monte_carlo_DEBUNKING_stats_YYYYMMDD-HHMMSS.json
```

## Output Files

A single simulation creates a folder such as:

```text
simulation_results_YYYYMMDD-HHMMSS/
```

It contains:

| File | Description |
|---|---|
| `simulation.log` | Simulation log. |
| `round_*.json` | Per-round simulation results. |
| `simulation_summary_*.json` | Full simulation summary. |
| `post_history_*.json` | All generated posts. |
